Resumen del proyecto

Terraform Docker Lab

Todo lo que hicimos, paso a paso, con los comandos explicados.

1Preparación del entorno

Comprobar versiones de Terraform y Docker dentro de WSL.
terraform version
docker --version
docker ps
Instalar Terraform en Ubuntu/WSL (una sola vez).
# Añadir la clave GPG de HashiCorp
curl -fsSL https://apt.releases.hashicorp.com/gpg | sudo gpg --dearmor -o /usr/share/keyrings/hashicorp-archive-keyring.gpg

# Añadir el repositorio
echo "deb [signed-by=/usr/share/keyrings/hashicorp-archive-keyring.gpg] https://apt.releases.hashicorp.com $(lsb_release -cs) main" | sudo tee /etc/apt/sources.list.d/hashicorp.list

# Instalar
sudo apt update
sudo apt install -y terraform
Arreglar permisos de Docker en WSL (para no usar sudo).
sudo usermod -aG docker $USER
# Salir de WSL y volver a entrar para aplicar el cambio
exit
wsl

3Flujo de Terraform

Inicializar el proyecto: descarga el provider de Docker.
terraform init
Formatear los archivos con el estilo oficial.
terraform fmt
Validar la sintaxis sin tocar nada.
terraform validate
Previsualizar qué va a hacer (no toca Docker).
terraform plan
Aplicar los cambios: crea imágenes, red, volumen y contenedores.
terraform apply
Ver los outputs definidos en outputs.tf.
terraform output
Listar los recursos que Terraform gestiona.
terraform state list
Destruir todo lo creado (cuando quieras limpiar).
terraform destroy

5El volumen del HTML

En main.tf, dentro del contenedor nginx:
volumes {
  host_path      = "${abspath(path.root)}/html"
  container_path = "/usr/share/nginx/html"
}
${abspath(path.root)} convierte la ruta relativa del proyecto en absoluta. Es lo que Docker necesita para el bind mount.
Ojo: si borras html/index.html, nginx devuelve 403/404. El contenedor sigue vivo. Vuelve a crearlo o haz git checkout html/.

7CI con GitHub Actions

En cada push o PR, GitHub ejecuta:
terraform init
terraform fmt -check -recursive
terraform validate

Si el workflow sale en verde ✅, todo está correcto. Si sale en rojo ❌, hay un error de formato o sintaxis.
